ESP32-CAM + DHT11 | แสดงอุณหภูมิและความชื้นบนมือถือ
บอร์ดเป้าหมาย: AI Thinker ESP32-CAM (ESP32 รุ่นเดิม ไม่ใช่ S3)

สิ่งที่โปรเจคทำ
- บอร์ดสร้าง Wi-Fi เอง มือถือเปิดเว็บดูค่าได้โดยไม่ใช้อินเทอร์เน็ต
- อ่านอุณหภูมิ °C และความชื้นสัมพัทธ์ %RH ทุก 2.5 วินาที
- แสดงสถานะอ่านไม่ได้/ขาดการเชื่อมต่อ โดยไม่แสดงค่าเก่าค้างว่าเป็นค่าปัจจุบัน
- มี Serial Monitor และ JSON ที่ /api สำหรับตรวจสอบ
- ไม่เริ่มกล้อง ไม่ใช้ MicroSD ไม่ส่ง Telegram และไม่เก็บประวัติข้ามการปิดเครื่อง

อุปกรณ์และการต่อสาย (ตัดไฟก่อนต่อ)
1. ESP32-CAM AI Thinker และฐานอัปโหลด USB หรือ USB-to-TTL ที่ใช้สัญญาณ 3.3V
2. DHT11 โมดูล 3 ขาที่รองรับ 3.3V หรือ DHT11 ตัวเปล่า 4 ขา
3. สาย Jumper; ตัวเปล่าต้องเพิ่ม R 10k ohm ระหว่าง DATA กับ 3V3
DHT11 VCC/+ -> ESP32-CAM 3V3
DHT11 DATA/S/OUT -> ESP32-CAM IO13 (GPIO13)
DHT11 GND/- -> ESP32-CAM GND
โมดูล 3 ขาเรียงขาไม่เหมือนกันทุกยี่ห้อ ให้ดูข้อความบนบอร์ด ไม่ใช้สีสายเป็นเกณฑ์
ตัวเปล่า 4 ขา เมื่อมองด้านตะแกรง ขาชี้ลง: ซ้ายไปขวา VCC, DATA, NC, GND
ขา NC ไม่ต่อ โมดูลส่วนมากมี pull-up แล้ว ให้ตรวจแผงก่อนเพิ่ม
จ่ายไฟบอร์ดผ่านฐาน USB หรือขา 5V/GND ด้วยแหล่งจ่าย 5V เสถียร
แนะนำแหล่งจ่ายที่รองรับอย่างน้อย 1A และสาย USB สั้นคุณภาพดี
ห้ามต่อ 5V เข้าขา DATA/GPIO13 หรือ 3V3
ถ้าโมดูลใช้ 3.3V ไม่ได้ ห้ามเปลี่ยนไป 5V แล้วต่อ DATA ตรง: ต้องใช้ level shifter
แบบสองทิศทางที่เหมาะกับสัญญาณ DHT หรือเปลี่ยนเป็นโมดูลที่รองรับ 3.3V
GPIO13 ใช้ร่วมกับ MicroSD: ถอดการ์ดและไม่เรียก SD_MMC ในโปรเจคนี้
วาง DHT11 ห่างบอร์ด/แหล่งความร้อน และไม่ให้โดนน้ำ

Arduino IDE
1. Preferences > Additional boards manager URLs เพิ่ม
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
2. Boards Manager: ติดตั้ง esp32 by Espressif Systems
3. Library Manager: ติดตั้ง DHT sensor library by Adafruit
   และ Adafruit Unified Sensor by Adafruit (เลือก Install all หากถาม)
4. แตก ZIP แล้วเปิด ESP32_CAM_DHT11/ESP32_CAM_DHT11.ino
   เก็บ config.h และ web_page.h ในโฟลเดอร์เดียวกัน
5. Tools > Board > esp32 > AI Thinker ESP32-CAM และเลือก Port ของบอร์ด
   ใช้ค่าเริ่มต้นของโปรไฟล์บอร์ด; Upload Speed 115200 หากมีตัวเลือก
6. แก้ชื่อ Wi-Fi และรหัสใน config.h ได้ รหัส 8-63 ตัวอักษร ASCII
7. Upload; หากฐานไม่มีวงจรเข้าโหมดอัปโหลดอัตโนมัติ ให้ต่อ IO0-GND
   แล้วกด RST ก่อนอัปโหลด หลังอัปโหลดถอด IO0-GND และกด RST อีกครั้ง
   ถ้าใช้ USB-to-TTL: TX->U0R, RX->U0T, GND ร่วม และสัญญาณ TX/RX ต้องเป็น 3.3V
   เลือกแหล่งจ่ายบอร์ดชุดเดียว ไม่ต่อเอาต์พุต 5V สองแหล่งเข้าด้วยกัน
8. เปิด Serial Monitor 115200 baud

เปิดดูบนมือถือ
Wi-Fi: ESP32-DHT11
รหัส: 12345678
เลือกเชื่อมต่อเครือข่ายต่อ แม้มือถือแจ้งว่าไม่มีอินเทอร์เน็ต
เปิด Chrome/Safari แล้วพิมพ์ http://192.168.4.1 ในช่องที่อยู่ (ไม่ใช่ช่องค้นหา)
รอค่าแรกประมาณ 2.5 วินาที หน้าเว็บโหลดข้อมูลต่อเนื่องโดยอัตโนมัติ
ปุ่มโหลดข้อมูลล่าสุดจะดึงค่าที่อ่านไว้ ไม่บังคับอ่านเซนเซอร์ถี่ขึ้น
Mobile_Preview.html เป็นภาพตัวอย่างแบบเปิดออฟไลน์ ใช้ค่าจำลอง ไม่ใช่ข้อมูลจากบอร์ด

การแก้ปัญหา
- ไม่มีชื่อ Wi-Fi: ถอด IO0-GND หลังอัปโหลด กด RST ดู Serial และตรวจแหล่งจ่าย
- เว็บไม่ขึ้น: ตรวจ Wi-Fi, ใช้ http ไม่ใช่ https, หยุด VPN หรือการสลับ Wi-Fi อัตโนมัติชั่วคราว
- อ่านเซนเซอร์ไม่ได้: ตรวจขาตามฉลาก, GPIO13, GND ร่วม, pull-up, ชนิด DHT11 และสายที่สั้น
- ค่าไม่เปลี่ยนทันที: DHT11 ตอบสนองช้าและละเอียดจำกัด ลองย้ายไปบริเวณอากาศต่างกัน
- ค่าสูงผิดปกติ: ย้ายเซนเซอร์ห่างบอร์ดและแสงแดด ไม่จับตัวเซนเซอร์ขณะเปรียบเทียบ
- หลังเปิดเครื่องต้องมีการอ่านสำเร็จก่อน หน้าเว็บจึงจะแสดงตัวเลข ไม่ใช้ค่าจำลองแทนเซนเซอร์

กิจกรรมสำหรับอบรม (ไม่กำหนดระยะเวลาฝึก)
ต่อสาย -> อัปโหลด -> เชื่อม Wi-Fi -> อ่านและอธิบายค่า
เปรียบเทียบอุณหภูมิ/ความชื้นสองตำแหน่ง โดยไม่เปลี่ยนเซนเซอร์และวิธีวาง
%RH เป็นความชื้นสัมพัทธ์ จึงเปลี่ยนตามอุณหภูมิได้ ไม่ใช่เปอร์เซ็นต์น้ำในห้อง
ใช้เรียนรู้และสังเกตสภาพแวดล้อม ไม่ใช่เครื่องมืออ้างอิงความแม่นยำสูง
