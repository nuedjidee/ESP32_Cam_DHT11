ผลตรวจโครงการ ESP32-CAM DHT11
- คอมไพล์ผ่าน: Arduino CLI, esp32 core 3.3.1, FQBN esp32:esp32:esp32cam
- DHT sensor library by Adafruit 1.4.6; Adafruit Unified Sensor 1.1.15
- Flash: 977,067 / 3,145,728 bytes (31%)
- Global RAM: 45,084 / 327,680 bytes (13%)
- ทดสอบหน้าเว็บด้วย API จำลอง: รอค่า, อ่านสำเร็จ, เซนเซอร์ผิดพลาด,
  ข้อมูลหมดอายุ, เครือข่ายขาด และเชื่อมต่อกลับ ผ่านทั้งหมด
- ตรวจจอขนาด 320, 390 และ 900 px: ไม่มีเนื้อหาล้นแนวนอน
- ตรวจ PDF ทั้ง 4 หน้าและภาพตัวอย่างแล้ว
- ยังไม่ได้ทดสอบกับ ESP32-CAM และ DHT11 จริง
- การคอมไพล์ผ่านไม่ยืนยันสายไฟ คุณภาพแหล่งจ่าย หรือความเข้ากันได้ของโมดูลแต่ละยี่ห้อ
